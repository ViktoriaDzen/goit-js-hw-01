# goit-js-hw-01

Домашнє завдання №1 з JavaScript.

```text
goit-js-hw-01/
├── js/
│   ├── task-1.js
│   ├── task-2.js
│   └── task-3.js
├── .gitignore
├── .prettierrc
├── index.html
└── README.md
```

Відкрийте `index.html` у браузері та консоль інструментів розробника.
Три файли задач підключені через `defer` і виконуються в порядку 1–3.
Файли задач поки містять лише коментарі: умови задач ще не додані.

Налаштування форматування Prettier зберігаються у `.prettierrc`.
Файл `.gitignore` виключає залежності, тимчасові файли, журнали та секрети `.env`.
